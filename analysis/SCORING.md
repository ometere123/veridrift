# Frozen independent analysis specification

Freeze date: 2026-11-16 WAT. This scoring plan was written before access to the main experimental outcomes. See `research/frozen_protocol.md` for prompts, branch assignment, and generation. The independent program reads the synthetic rubric and re-parses raw content without importing the runner or treating its parser as ground truth.

- Independent unit: original evidence task. Fixed claims within a task are repeated measurements. Branches and conditions are matched on task. The four conditions are A (direct), B (ordinary), C (provenance), and D (provenance plus uncertainty).
- Primary endpoint: among claims whose reference status is unresolved or contradicted in the no-new-evidence branch, count a claim when the response status is supported and its integer claim-truth confidence is strictly greater than 80/100. Report unresolved and contradicted strata separately. A high confidence number without an asserted supported status is reported separately as a diagnostic. The primary contrast is D minus B, in percentage points, using the mean of within-task rate differences. D minus C and B minus A are descriptive contrasts. Negative differences favor the first condition named.
- Evidence-free amplification: final-minus-shared-initial claim-truth confidence, averaged first within each task over the same at-risk claims. Report the signed mean difference and the number of at-risk slots whose confidence increases, with B/C/D paired between-condition contrasts. A has no within-path handoff change.
- Evidence fidelity: an eligible resolution is any supported or contradicted reference claim. Its strict fidelity indicator is correct verdict and exact match of cited identifiers to the reference citation set. Also report precision over citations the model actually emitted, with a cited ID eligible only when claim polarity matches the reference and its ID appears in that claim's branch rubric. An unresolved reference claim has no decisive source under this rubric. Citation precision measures decisive evidence attribution under this rule, and does not score citations as a comprehensive measure of narrative quality.
- Appropriate revision: in the support and retract branches, evaluate the target for correct final polarity and decisive source. The signed change from the same condition's no-new final is positive when claim confidence rises after support or falls after retraction. Report mean signed change and the fraction with both correct verdict/source and strict positive signed change, conditional on valid matched finals and an unresolved verdict in the no-new final. Also report post-update strict fidelity regardless of prior verdict to expose ceiling effects and empty eligible strata.
- Abstention: report correct unresolved verdicts over the unresolved reference stratum and unresolved verdicts over determinate references separately. Report source-relative verdict accuracy over all fixed claims. Confidence is model self-report, and no calibration or latent truth inference is planned.
- Missingness: classify absent record, transport/no-content failure, invalid schema (including duplicate JSON keys), and valid independently decoded output. The primary descriptive rate uses valid records. Give worst/best case bounds over all planned at-risk slots. Between-condition differences use complete task pairs only, with the number lost reported. Identity mismatches or disagreement between the independent parser and a logged successful parse are integrity errors to investigate before relying on the output.
- Intervals: 10,000 percentile bootstrap draws of equally weighted task-pair differences, using a fixed seed of 20261116. Report intervals with at least eight complete task pairs. Repeated and all-equal pairs can make these intervals degenerate, so bounds and sample size remain essential. Results are descriptive for this benchmark. Similarity between synthetic templates means these intervals can understate broader-domain uncertainty. No null-hypothesis significance claims.
- Examples: select the first task and candidate in lexicographic order in each observed pattern and protocol (unsupported high-confidence assertion, a correct upward or downward update, and an incorrect update). Carry through exact case/source identifiers and source text. This rule illustrates categories without selecting for dramatic effects. Keep denominators attached to every measured quantity where applicable.

Two diagnostics were recorded before the main run: unsupported assertions at any confidence, and amplification stratified by unsupported versus contradicted baseline reference status. These protect against a threshold floor or a pooled signed average concealing changes in either stratum.

Two additional descriptive contrasts treat D minus B on post-update exact target verdict and citation as a paired risk difference, separately by update branch. The retraction branch also reports the exact negative verdict and decisive citation among trials whose shared stage-one assessment endorsed the target. An empty denominator for this measure means the test exercised late contradiction without observing retraction of a prior endorsement.
